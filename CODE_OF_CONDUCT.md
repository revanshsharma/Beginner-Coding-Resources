# Code of Conduct

## Our standard

Everyone who participates in this project is expected to be respectful, patient, and constructive. Beginners should be able to ask questions without being mocked, and experienced contributors should explain corrections clearly.

Unacceptable behaviour includes harassment, insults, discrimination, threats, unwanted personal contact, and publishing someone else's private information.

## Reporting a problem

If you experience or witness unacceptable behaviour, contact the repository owner through [Revansh Sharma's LinkedIn profile](https://www.linkedin.com/in/revansh-sharma-836286347/) or a private GitHub message. Please include what happened, where it happened, and any relevant links. Reports will be handled privately and reviewed in good faith.
