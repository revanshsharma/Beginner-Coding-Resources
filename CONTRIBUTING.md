# Contributing

Thanks for helping make this starter pack more useful for beginners.

## Good contributions

- Fix inaccurate commands, spelling, or broken links.
- Add short explanations that a first-time learner can understand.
- Add small, dependency-free examples with clear filenames.
- Keep instructions focused on Windows unless a section says otherwise.
- Do not add passwords, API keys, personal data, or large installer files.

## Before opening a pull request

1. Make a branch for your change.
2. Keep each commit focused on one improvement.
3. Test commands and examples on a clean terminal where possible.
4. Check that Markdown links and code fences render correctly.
5. Explain what changed and how you tested it.

For a small typo or link correction, a direct pull request is welcome. For a large new section, open an issue first so the content can be discussed.
