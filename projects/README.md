# Beginner Project Ideas

Choose one project that feels slightly challenging but still finishable in a weekend. Start with a plain version, then add one improvement at a time.

| Project | Skills to practise | First version |
| --- | --- | --- |
| Calculator | Variables, input, functions | Add, subtract, multiply, and divide two numbers. |
| Quiz game | Conditions, loops, score keeping | Ask five questions and show the score. |
| To-do list | Lists, file input and output | Add, view, and remove tasks. |
| Personal webpage | HTML, CSS, links | Create an about page with a project list. |
| Number guessing game | Random numbers, loops | Let the player guess a hidden number. |
| File organiser | Paths, folders, error handling | Move files into folders by extension. |

## A simple project routine

1. Write down what the program should do in three sentences.
2. Build the smallest working version.
3. Test a normal input, an empty input, and an unexpected input.
4. Save a Git commit when one useful piece works.
5. Add one improvement and update the README with how to run it.
