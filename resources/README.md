- [MDN Web Docs](https://developer.mozilla.org/) - HTML, CSS, and JavaScript reference
- [C++ reference](https://en.cppreference.com/w/) - C and C++ language reference

## Helpful habits

- Read the complete error message before searching for it.
- Change one thing at a time so you know what fixed the problem.
- Use official documentation to confirm advice from tutorials.
- Keep a short notes file with commands that worked for your setup.
- Explain your code to yourself or someone else; gaps become easier to spot.
